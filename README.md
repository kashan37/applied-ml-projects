# Applied ML 

A collection of applied machine learning notebooks covering classification and regression tasks using real-world datasets.

## Notebooks
- Random Forest vs XGBoost
- K-Nearest Neighbors
- Multiclass Classification
- Rainfall Prediction
- SVM & Decision Trees

Python (scikit-learn, pandas, matplotlib), XGBoost, R

To practice and demonstrate practical machine learning workflows, including preprocessing, model training, and evaluation.
